# 需求与成功标准

用户是内容运营人员。目标是知道每项素材是否合规、有没有明确的排期冲突、下一步要补什么，以及草稿是否确实保存。

输入包含请求 ID 和 1–8 个不重复素材 ID；每项指定一个渠道和带时区的硬性时段。素材、规则、已有时段为合成数据。一次处理一项，批次允许部分成功。一个渠道在同一时刻只允许一个占用；已保存草稿占用排期，替代建议不占用。渠道内只比较离散时间点，不处理任意持续区间。候选查找只覆盖同渠道同日往后 1–3 小时。

输出逐项包含审核、排期与写入状态，缺失字段、规则依据、建议时段及确认状态、草稿 ID 和失败原因。正常可保存；缺资料和规则风险不保存；时段冲突只给建议；重放不重复写；写入失败不虚报成功。还需真实模型根据空闲和占用的不同工具结果走出两条路径，并在达到预算后明确停止。

V1 只保存草稿。替代时段需由用户确认后以新请求提交；没有发布、认证、线上部署或续跑旧对话。
