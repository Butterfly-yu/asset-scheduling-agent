# AI 使用说明

Codex 辅助需求拆解、设计比较、代码、自动测试、故障注入、真实模型运行及评估文档。候选人参与选题、供应商选择、本机配置、提出复查和迭代需求。真实验收命令由 Codex 执行；结果见 [评估记录](03-evaluation.md)。

初版真实轨迹中，模型看到候选后多发起了一次保存请求，被系统拒绝。这轮迭代增加了按状态提供的工具、具体故障码和可持久化的人工确认。相关回归包括无授权调用、时段被抢占、规则发生变化、重放和事务回滚。Codex 实现了轨迹评测器，通过工具调用顺序和数据库快照验证动作与业务结果。提交前请由候选人补充自己亲自复查的代码、修改、验证结果和实际用时。项目只提交合成数据和脱敏轨迹；真实密钥留在被 Git 忽略的本机配置。
